# 湖南跑胡子 · 多人联机版

一个纯 HTML/CSS/JS + Node.js（零第三方依赖）实现的湖南跑胡子（字牌）联机游戏网站。

## 快速开始

需要 [Node.js](https://nodejs.org/) 18+（无需安装任何 npm 依赖）：

```bash
node server/server.js
```

或双击 `启动服务器.bat`。启动后按提示访问：

- 本机：`http://127.0.0.1:3456`
- 同一 WiFi/局域网：把 `http://<你的IP>:3456` 发给同网络的朋友（首次需双击 `防火墙放行.bat` 放行端口）

### 异地联机（朋友不在同一网络）

需要内网穿透，把本机服务器映射成公网网址：

1. 保持游戏服务器运行（`启动服务器.bat`）；
2. 安装穿透工具（推荐 **cpolar**：浏览器打开 <https://www.cpolar.com> 免费注册，下载 Windows 版，把 `cpolar.exe` 解压到本目录）；
3. 双击 `异地联机穿透.bat`，首次粘贴 cpolar 的 Authtoken（官网「验证」页复制），之后自动启动隧道；
4. 把输出中的 `https://xxxx.cpolar.top` 地址发给朋友，异地即可打开联机（房间码加入）。

备选工具：ngrok（<https://ngrok.com> 注册后下载 `ngrok.exe` 放本目录）；cloudflared（无需注册，国内可能较慢）。

端口被占用会自动顺延（3457、3458…）。

## 玩法

- **发牌**：3 人局与 4 人局均为每人发 14 张（庄家摸后 15 张），胡牌 = **5 句话**（3 人局剩 38 张、4 人局剩 24 张为牌堆）；
- **庄家开局**：庄家比其他玩家多摸一张牌（15 张），最后摸到的那张牌公开亮出展示（开局这张不可抢），随后有 **20 秒理牌时间**（可拖动整理手牌），理完牌**庄家直接出牌**（不再摸牌），打出手牌中的任意一张牌；
- **一句话**包括：同字号三连（一二三…）、二七十（贰柒拾，与一二三同规则）、**同数混搭**（如 叁三三 / 三三叁）；
- **煨**：手中有 3 张相同，在**摸牌前**亮出——**跳过摸牌阶段**（不摸牌、不出牌），直接轮到下家；**摸到的牌若与手中两张相同（成煨）或与桌上碰/煨凑成第四张（成跑），强制亮出，不可拆散**；摸牌后展示留 5 秒思考时间；
- **组合**：出牌阶段可用刚摸到的牌 + 手中两张组成吃/碰形式，若可以则亮出并记入胡息，然后打一张；若不可以则不允许；
- **胡牌条件**：手牌组成 **5 句话**（吃、碰、煨、跑、提都算）；**每组跑牌少一句话、多一对对子**（对子无胡息）；6 胡起胡；
- 每回合摸 1 张、打 1 张，可用别人打出的牌 **吃 / 碰 / 跑**，手牌可 **煨 / 提**；
- **一句话**：同字号三连（一二三、二三四…）或 **二七十（贰柒拾）**——二七十与一二三同规则、同胡数；
- **亮牌玩法**：每次摸牌公开亮出（桌面中央展示），并留有 10 秒思考时间（全机器人时自动跳过），之后开启抢牌窗口；其余玩家可抢 **胡 / 跑 / 碰 / 吃**（吃仅限下家）；按优先级结算：胡 > 跑 > 碰 > 吃，同优先级按座位顺序，摸牌者自摸胡最优先；摸牌者不提供「保留此牌」操作——无人要牌时自动留牌继续，按顺序进行；
- **跑牌**：亮成四张，**不补牌**，跑后照常打一张（自己摸到第 4 张必须跑，同样不补牌）；胡牌结构**每有一组跑牌就多一对将**（跑的四张 = 一坎 + 一张将），对子计入胡数（小字黑 1 / 小字红 2 / 大字黑 3 / 大字红 4）；
- **起胡线：6 胡**。

### 胡数表

| 牌型 | 胡数 |
| --- | --- |
| 一句话 · 小字 一二三 / 二七十 | 1 |
| 一句话 · 大字 壹贰叁 / 贰柒拾 | 3 |
| 一句话 · 其他句子 / 混搭 | 0 |
| 碰 · 小字（红黑同） / 大字（红黑同） | 1 / 3 |
| 煨 · 小字 / 大字 | 3 / 6 |
| 跑 / 提 · 小字 / 大字 | 6 / 12 |
| 对子（将） | 0 |

### 特殊胡型（倍数）

自摸 ×2 · 天胡 ×4 · 地胡 ×2 · 十八小 ×2 · 十八大 ×2

### 随时点胡与诈胡

- 「胡」按钮在牌桌上<b>任何时候都可点击</b>，界面不会提示当前能否胡牌；
- 点击后由服务器判定：符合条件（牌型成立且胡数 ≥ 6，接炮时不能胡自己打出的牌）即胡牌；
- 不符合条件判<b>诈胡</b>：各赔另外两家 10 分，对局继续。

### 结算

- 自摸：其余各家各付总分（胡数 × 倍数）；
- 接炮：放炮者付 2 倍总分，其余各家各付 1 倍；
- 荒庄（牌墙摸完）：流局、分数不变、原庄家连庄；胡牌者下局坐庄。

## 功能

- 房间制联机：6 位房间码加入，支持 3 人局 / 4 人局，支持局域网/同机多标签页；
- 实时同步：SSE 推送个性化视图（他人手牌不可见），服务器权威校验每一步；
- 机器人陪玩：房主可添加，机器人会吃碰煨跑、主动胡牌；
- 断线托管：掉线或点「托管」后系统自动出牌，60 秒未操作也会自动出牌；
- 聊天、分数累计、多局连庄；
- 牌桌交互：手牌以 3×5 网格排列（15 张时 3 行 ×5 列，14 张时 3×5−1）；拖动牌调整手牌顺序：**跨行拖到某张牌上 = 上下两张牌换位**，行内拖动 = 插入排序（插入点按指针实时定位，横轴按牌中心线、纵轴按行间隙中点判定，松手时按最终坐标精确落位，拖拽后不会误触发点击；服务器记住顺序，刷新不丢）；轮到出牌时把牌拖到中间牌区即可打出（或点击选牌再点「出牌」）；顶栏实时显示「当前胡数」。

## 测试

```bash
node --test test/engine.test.js test/integration.test.js
```

- `engine.test.js`：规则引擎单元测试 + 300 局机器人模拟对局（校验 80 张牌守恒、手牌结构不变量、胡牌数值）；
- `integration.test.js`：进程内启动服务器，模拟 1 真人 + 2 机器人完整打一局。

## 说明

- 房间数据保存在内存中，重启服务器后房间清空；
- 胡牌结构采用「21 张全面子（无将）」模型：自摸 21 张 = 7 组面子，接炮 20 + 1 = 7 组面子，桌面已亮出的面子计入总数。煨牌不补牌；提、跑补摸 1 张；摸到跑牌必须跑。
